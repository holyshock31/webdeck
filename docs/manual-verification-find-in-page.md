# 页内查找手动验收清单（add-find-in-page）

> 对应 `openspec/changes/add-find-in-page` 的手动验收方式（webdeck-core 规格增量：
> 「页内查找入口」「查找结果计数与上下翻找」「查找生命周期与视图隔离」）。
> 前置：`npm start` 启动开发态 WebDeck，并添加至少两个应用（建议一个内容较长的本地静态服务页面、一个 DeepSeek Harness）。

## 通用前置

- [ ] `npm test` 全部通过（含测试 12 查找会话状态机单测）

## macOS 手测

- [ ] 按 ⌘F，内容区右上角出现查找栏且输入框自动聚焦；页面无任何 DOM 注入（页面感知不到查找栏存在）
- [ ] 输入关键词（如 `webdeck`），页面内所有匹配文本即时高亮，无需回车
- [ ] 查找栏显示计数 `n/m`（如 `1/5`），输入变化时计数实时更新
- [ ] 按 Enter 跳到下一处（计数前进，页面滚动跟随）；Shift+Enter 跳到上一处
- [ ] 按 ⌘G / ⇧⌘G 与 Enter / Shift+Enter 等效；翻到最后一处后再按 Enter 回绕到第一处
- [ ] 输入不存在的关键词，计数显示 `0/0`，页面可正常继续操作
- [ ] 删空输入框，高亮立即清除、计数消失
- [ ] 按 Esc（或点 ✕）关闭查找栏，页面高亮清除，焦点回到应用页面（快捷键继续作用于应用）
- [ ] 查找栏关闭状态下按 ⌘G 无任何效果（不弹查找栏、不报错）
- [ ] 查找栏打开时再次按 ⌘F，输入框重新聚焦并选中已有内容
- [ ] 点击查找栏 ↑/↓ 按钮可翻找，按钮不抢输入框焦点
- [ ] 切换浅色/深色主题后按 ⌘F，查找栏样式跟随主题；主题切换后查找栏输入内容与计数不丢失
- [ ] 查找高亮后切换侧边栏应用：查找栏关闭、原应用高亮清除，新应用无残留查找状态
- [ ] 查找过程中打开「添加应用」弹窗：查找栏隐藏；关闭弹窗后查找栏恢复显示
- [ ] 查找高亮后点击 ↻ 重载当前应用：查找栏关闭，重载后页面无高亮残留
- [ ] 编辑菜单出现「在页面中查找…」/「查找下一处」/「查找上一处」三项，加速键显示 ⌘F / ⌘G / ⇧⌘G

## 回归

- [ ] 既有快捷键不受影响：⌘1–⌘9 切换、⌘N 添加、⌘R 重载、⌘\ 侧边栏、⌘⌥I 开发者工具
- [ ] 侧边栏收起态下按 ⌘F：查找栏出现在窗口右上角（不依赖侧边栏区域），展开/收起不影响查找
- [ ] 打包版（`npm run dist:mac` 产物或开发态）行为一致
