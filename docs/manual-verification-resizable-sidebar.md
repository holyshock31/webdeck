# 侧边栏宽度可调手动验收清单（add-resizable-sidebar）

> 对应 `openspec/changes/add-resizable-sidebar` 的手动验收方式（webdeck-core 规格增量：
> 「侧边栏宽度可调」「侧边栏宽度持久化」，及「侧边栏支持收起与展开」的「展开时以持久化宽度恢复」表述）。
> 前置：`npm start` 启动开发态 WebDeck，并添加至少两个应用。

## 通用前置

- [ ] `npm test` 全部通过
- [ ] `npm run smoke` 输出 `SMOKE_OK`（含 SMOKE_RS_* 宽度调整断言）

## macOS 手测

- [ ] 侧边栏右边界出现约 6px 宽的分隔条，悬停时光标变为 col-resize 且分隔条高亮
- [ ] 按住分隔条向右拖动，侧边栏宽度实时增加、主内容区同步变窄，全程无闪烁、无文本选中态（拖动中全局光标为 col-resize）
- [ ] 向左拖动，宽度实时减小、主内容区同步变宽；释放后宽度保持
- [ ] 把分隔条拖到窗口宽度一半以上，宽度停在窗口一半处不再增大（应用视图左缘与分隔条对齐，无遮挡/空隙）
- [ ] 把分隔条拖到 180px 以下，宽度停在 180px 不再减小
- [ ] 释放后退出并重新启动 WebDeck，侧边栏以上次宽度显示，无需重新拖动
- [ ] 把宽度拖到 320px 后收起侧边栏（⌘\ 或头部按钮）：分隔条随之隐藏、不可拖；展开后侧边栏仍以 320px 恢复，宽度不被重置
- [ ] 收起态下右边界无分隔条可拖（指针悬停无 col-resize 光标）
- [ ] 拖动后切换应用标签，激活的应用页面左缘始终与侧边栏右缘对齐（原生视图跟随宽度）
- [ ] 新装环境（删除 webdeck.json）启动，侧边栏宽度为默认 252px
- [ ] 配置中写入非法 sidebarWidth（如字符串/超界值）启动，宽度回退 252px 且不报错

## 回归

- [ ] 收起/展开、⌘\ 快捷键、浮动展开按钮行为与引入前一致
- [ ] 页内查找栏（⌘F）位置随侧边栏宽度右移，不被侧边栏遮挡
- [ ] 主题切换（🌙/☀️）后分隔条高亮在 dark/light 下均可辨识
