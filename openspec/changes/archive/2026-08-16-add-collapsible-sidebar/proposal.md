## Why

侧边栏（品牌区 + 工具栏 + 应用列表 + 底部状态区）常驻窗口左侧，挤压内嵌应用的浏览空间——尤其对 DeepSeek Harness 这类需要宽视野的工具页面。当前侧边栏不可收起，用户无法在专注浏览内容时临时让出左侧空间。希望侧边栏可收起：需要时收起获得全宽内容区，随时可一键或快捷键重新展开，且收起状态重启后保持。

## What Changes

- 新增变更目录 `openspec/changes/add-collapsible-sidebar/`，以 `webdeck-core` 的 `## ADDED Requirements` 增量规格化：
  1. 侧边栏收起/展开切换入口：侧边栏头部按钮 + `⌘\` 快捷键；收起时侧边栏隐藏、主内容区占满窗口，展开时恢复原宽度与布局
  2. 收起/展开状态持久化：`settings.sidebarCollapsed` 随 webdeck.json 原子写入，重启保持，配置缺失时默认展开（与现状一致）
  3. 收起状态下应用仍可访问：`⌘1–⌘9`/`⌘N` 快捷键继续生效，窗口左缘提供浮动展开按钮，健康监测与状态更新不受影响
  4. 收起/展开控件（按钮、浮动入口）沿用主题变量，dark / light 两种主题下均可辨识
- 新增 `proposal.md`（本文件）与 `tasks.md`
- 范围：新增能力；验收方式为手动验证；本次仅产出规格提案，不涉及实现

## Impact

- **运行时行为**：仅渲染层（index.html / styles.css / app.js）布局与交互变化；应用配置、进程管理、健康监测、IPC 均不变
- **持久化**：settings 增加可选字段 `sidebarCollapsed`，缺失时默认展开，旧配置无需迁移
- **兼容性**：收起/展开不影响应用会话、登录态隔离、`⌘1–⌘9` 标签切换；webdeck-theming 的主题规则继续覆盖新控件
- **风险**：低；主要风险是收起后缺少展开入口导致界面无法恢复，需保证浮动按钮与快捷键始终可用
- **范围边界**：本次仅做整体收起/展开（隐藏侧边栏），不做折叠为窄图标栏、拖拽调宽或自动收起
