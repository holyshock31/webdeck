# WebDeck Theming Specification

## ADDED Requirements

### Requirement: 壳界面提供主题切换入口

WebDeck 自身 UI（侧边栏）提供主题切换入口，可在暗色（dark）与浅色（light）两种主题间切换；切换立即生效，无需重启；当前主题有明确视觉指示。

#### Scenario: 切换到浅色主题

用户点击侧边栏工具栏的主题切换按钮，界面立即变为浅色：侧边栏背景由深色（#14161c 系）变为浅色，文字颜色同步调整且可读。

#### Scenario: 切换回暗色主题

用户再次点击主题切换按钮，界面恢复为暗色主题，与当前默认外观一致。

### Requirement: 主题作用于全部自身 UI

主题切换影响 WebDeck 自身的所有界面元素：侧边栏、添加/编辑应用弹窗、日志查看弹窗、底部状态栏；内嵌的远程应用页面不受影响（它们运行在独立 WebContentsView 中）。

#### Scenario: 弹窗跟随主题

浅色主题下打开"添加应用"弹窗或"启动日志"弹窗，弹窗背景与文字使用浅色主题样式。

#### Scenario: 远程页面不受主题影响

浅色主题下切换到一个内嵌应用标签（如 DeepSeek Harness），该页面显示保持其自身样式，不被 WebDeck 主题覆盖。

### Requirement: 状态灯在两种主题下均可辨识

运行状态灯四色（绿=运行中 / 黄=启动中 / 红=错误 / 灰=停止）在 dark 与 light 主题下均有足够对比度，颜色语义一致。

#### Scenario: 浅色主题下状态灯可辨识

浅色主题下，运行中的应用状态灯仍为清晰的绿色，错误状态为清晰的红色，与浅色背景对比可辨。

### Requirement: 主题选择持久化

用户选择的主题写入持久化配置（settings.theme），重启 WebDeck 后保持上次选择的主题；配置缺失或损坏时回退到 dark。

#### Scenario: 重启后保持所选主题

用户切换到浅色主题后退出并重新启动 WebDeck，侧边栏仍为浅色主题，无需重新选择。

#### Scenario: 无配置时默认暗色

全新安装或配置中无 theme 字段时，界面使用 dark 主题。
