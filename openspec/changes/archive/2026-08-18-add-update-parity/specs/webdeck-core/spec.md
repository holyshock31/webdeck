# WebDeck Core Specification

## ADDED Requirements

### Requirement: 更新内部日志全部落盘

electron-updater 内部日志（检查结果、下载源 URL、差分下载回退、staging 校验等）经 `autoUpdater.logger` 注入写入 `userData/logs/webdeck.log`（`[updater]` 前缀，与主进程链路同一落盘通道）——更新异常可从日志定位到内部环节，无需猜测。

#### Scenario: 差分下载失败回退在日志中可查

用户更新时差分下载失败，electron-updater 自动回退全量下载；`webdeck.log` 中出现内部日志行（含回退原因与下载 URL），据此可判断是差分环节还是全量环节出错。

#### Scenario: 开发态手动检查有日志记录

开发态（未打包）配置 `dev-app-update.yml` 后手动「检查更新」，`webdeck.log` 中出现检查结果与下载相关内部日志行。

### Requirement: 开发态可调试更新链路

开发态（`!app.isPackaged`）下 `autoUpdater.forceDevUpdateConfig = true`，更新服务读取仓库根 `dev-app-update.yml`（默认指向本地更新服务器）——开发者在本地即可验证检查/下载/取消/安装完整链路，无需发布真实版本或依赖真机。

#### Scenario: 开发态本地更新服务器联调

开发者把 `dev-app-update.yml` 指向本地静态服务器（存放构建产物与 `latest.yml`），开发态启动应用手动「检查更新」——发现新版本并下载成功，日志可见完整链路。

### Requirement: 发现新版本与下载完成发送系统通知

自动检查发现新版本、或更新包下载完成时，发送系统通知（`Notification.isSupported()` 守卫）——窗口不聚焦/最小化时用户也能感知更新。

#### Scenario: 后台发现新版有系统通知

应用在后台（窗口未聚焦）自动检查发现新版本，系统通知中心出现「发现新版本」通知；点击通知后应用窗口聚焦到前台。

#### Scenario: 下载完成有系统通知

更新包下载完成后出现「更新已就绪」系统通知，用户据此决定何时安装。

### Requirement: 更新状态跨重启持久化与版本忽略

更新状态（下载完成的版本、用户忽略的版本）持久化于渲染层 localStorage——下载完成未安装重启后提示仍存在（不白下载）；用户「忽略」的版本不再提示（含重启后），重新检查仍可下载。

#### Scenario: 下载完成未安装重启后提示保留

用户下载完成但未安装即退出应用；下次启动后提示条仍显示「新版本已就绪，可立即安装」，可继续安装。

#### Scenario: 忽略的版本不再提示

用户点击更新弹窗「忽略此版本」后，该版本不再弹出提示（重启后亦然）；再次「检查更新」可重新发起下载（新版本不受影响）。

### Requirement: 自动检查可关闭

帮助菜单提供「自动检查更新」开关（持久化于 `settings.autoUpdateEnabled`，默认开启）——关闭后调度循环空转（不发起检查、排程不取消），手动「检查更新」不受影响；重新开启后自动恢复。

#### Scenario: 关闭后不再自动检查

用户关闭「自动检查更新」，应用不再自动发起更新检查；手动「检查更新」仍可用并正常反馈。

#### Scenario: 重新开启后自动恢复

用户重新开启「自动检查更新」，后续调度周期自动检查恢复（无需重启）。

### Requirement: release notes 按语言偏好本地化

多语言 release notes（`<!--LANG:xx-->…<!--LANG:END-->` 标记）在**主进程**按应用语言（`app.getLocale()`）本地化后下发渲染层——双语用户看到的是单一语言内容，而非混排或整体被 strip 的文本。

#### Scenario: 双语 release notes 按应用语言显示

发布说明含中英双语标记块，应用语言为中文时弹窗显示中文段落，为英文时显示英文段落；无匹配语言时回退英文，无标记时显示原文。

### Requirement: 更新服务退出清理

应用退出（`will-quit`）时更新服务 `dispose()`——清除调度定时器并摘除全部 autoUpdater 事件监听器——不随进程生命周期残留。

#### Scenario: 退出无监听器残留

应用退出流程中更新服务监听器与定时器被清理（代码级验证，无用户可见行为变化）。
