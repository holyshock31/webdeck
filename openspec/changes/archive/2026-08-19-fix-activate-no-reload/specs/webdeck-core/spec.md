# WebDeck Core Specification

## MODIFIED Requirements

### Requirement: 多应用标签与登录态隔离

每个应用使用独立 session 分区（persist:webdeck-<id>），登录态互不串扰且重启保留；侧边栏点击应用切换标签**不重新加载目标应用页面**（页面状态保留）；重复点击当前应用同样不重新加载页面；需要重新加载时使用工具栏 ↻ 或快捷键 ⌘R；⌘1–⌘9 切换标签，应用菜单带勾选态。

#### Scenario: 两个应用的登录态互不影响

用户分别登录两个不同站点，退出并重新打开其中一个，另一个的登录态不受影响。

#### Scenario: 快捷键切换标签不重载页面

用户按下 ⌘2，主内容区切换到第二个应用，第二个应用的页面不被重新加载，此前打开时的页面状态（滚动位置、表单输入、SPA 状态）保留；再次点击侧边栏当前应用，页面同样不被重新加载。

#### Scenario: 加载失败后重新激活可重试

应用页面加载失败（如本地服务未启动）或渲染进程异常退出，用户修复后再次点击侧边栏该应用，页面重新加载并正常显示。
